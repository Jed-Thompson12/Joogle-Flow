**Step 1: prepare the Joogle Flow server.**

We'll assume we're using your **Windows PC** as the server. The goal of Step 1 is to get the basic development environment installed and create the project structure.

## Step 1A — Install the software

We need these four things:

1. **Git** — manages the Joogle Flow code
2. **Node.js** — runs the frontend
3. **Python** — runs the backend
4. **Docker Desktop** — runs our services in containers

### 1. Install Git

Go to the official Git website and install **Git for Windows**.

[Git for Windows](https://git-scm.com/download/win?utm_source=chatgpt.com)

During installation, the default options are fine.

### 2. Install Node.js

Install the **LTS** version.

[Node.js](https://nodejs.org/?utm_source=chatgpt.com)

### 3. Install Python

Install a current Python 3 release.

[Python](https://www.python.org/downloads/windows/?utm_source=chatgpt.com)

**Important:** during installation, tick:

> **Add python.exe to PATH**

before clicking Install.

### 4. Install Docker Desktop

[Docker Desktop](https://www.docker.com/products/docker-desktop/?utm_source=chatgpt.com)

Install it using the normal settings.

If Docker asks about **WSL 2**, allow it to install/enable it.

---

# Step 1B — Verify everything

Once those are installed, **restart Windows**.

Then open **PowerShell** and run:

```powershell
git --version
node --version
npm --version
python --version
docker --version
```

You should get something roughly like:

```text
git version 2.x.x
v22.x.x
10.x.x
Python 3.x.x
Docker version 2x.x.x
```

The exact versions don't matter.

---

# Step 1C — Create Joogle Flow

Now run:

```powershell
mkdir C:\JoogleFlow
cd C:\JoogleFlow
```

Create our initial directories:

```powershell
mkdir frontend
mkdir backend
mkdir data
mkdir storage
mkdir wireguard
```

You should now have:

```text
C:\JoogleFlow
│
├── backend
├── data
├── frontend
├── storage
└── wireguard
```

### Don't put the 1 TB HDD into the setup yet.

We'll first make sure Joogle Flow works correctly. **Then** we'll move `storage` onto the HDD.

---

## Step 1D — Initialise Git

Still in:

```text
C:\JoogleFlow
```

run:

```powershell
git init
```

Then:

```powershell
git status
```

You should see that you're on a new Git repository.
